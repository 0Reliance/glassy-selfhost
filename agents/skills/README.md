# Skills

The agent guides, packaged as skills for agents that load skills (Claude Code, Claude, and
others that read `SKILL.md` folders).

| Skill | Use it when | Full guide |
|---|---|---|
| [glassy-install](glassy-install/SKILL.md) | A person asks you to install Glassy on their machine | [INSTALL.md](../INSTALL.md) |
| [glassy-setup](glassy-setup/SKILL.md) | Glassy is installed and needs first sign-in, your key, and an AI choice | [CONFIGURE.md](../CONFIGURE.md) |
| [glassy-agent](glassy-agent/SKILL.md) | You are reading or writing in someone's Glassy | [USE.md](../USE.md) |

To install one in Claude Code, copy its folder into `~/.claude/skills/` (or the project's
`.claude/skills/`). Each skill is short and points at the full guide in this repository for
detail, so keep the repository checked out or reachable.
